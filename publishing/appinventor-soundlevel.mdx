# 앱 인벤터로 음악에 반응하는 RGB 화면 만들기

안드로이드 태블릿의 마이크로 음악을 입력받아 화면 색상을 바꾸는 수업용 확장 **SoundLevel**을 만들었습니다. 소리 크기를 색으로 바꾸는 기본 모드와 음악의 저음·중음·고음 비율을 색으로 혼합하는 Spectrum 모드를 제공합니다.

[SoundLevel.aix 다운로드](https://github.com/inbum/appinventor-soundlevel/releases/download/v4/SoundLevel.aix) · [소스 코드](https://github.com/inbum/appinventor-soundlevel) · [자세한 음악 모드 안내](https://github.com/inbum/appinventor-soundlevel/blob/main/MUSIC.md)

## 소리 크기에서 음악의 구성으로

소리 크기만 색상에 연결하면, 음악을 일정한 볼륨으로 재생할 때 화면 색상이 비슷하게 유지될 수 있습니다. Spectrum 모드는 전체 소리 크기 대신 세 주파수 대역의 에너지 비율을 분석해 색을 혼합합니다.

| 대역 | 주파수 범위 | 기본 RGB 테마 | Concert 테마 |
|---|---|---|---|
| 저음 | 80Hz 이상~300Hz 미만 | 빨강 | 보라 |
| 중음 | 300Hz 이상~2,000Hz 미만 | 초록 | 핑크 |
| 고음 | 2,000Hz 이상~8,000Hz 미만 | 파랑 | 라벤더 |

이는 음악을 하나의 정확한 음높이로 추정하는 기능과는 다릅니다. 여러 악기가 섞인 음악의 대역별 구성을 시각적으로 표현하는 활동에 적합합니다.

## 확장 추가하기

1. 위 링크에서 `SoundLevel.aix`를 내려받습니다.
2. 앱 인벤터 디자이너의 확장 기능에서 파일을 가져옵니다.
3. `SoundLevel`을 화면에 추가하면 보이지 않는 컴포넌트 `SoundLevel1`이 생깁니다.
4. 시작 버튼과 중지 버튼을 추가합니다.
5. 태블릿의 MIT AI2 Companion으로 연결합니다.
6. 시작 버튼을 누르고 Companion의 마이크 사용 권한을 허용합니다.

이 확장은 Android용입니다. 소리는 기기의 메모리에서 처리하며 녹음 파일을 저장하거나 서버로 전송하지 않습니다.

## Concert 테마로 보라·핑크 화면 만들기

기존 동작과의 호환성을 위해 기본 모드는 `Loudness`, 기본 테마는 `RGB`입니다. 음악용 색상을 사용하려면 시작할 때 다음과 같이 설정합니다.

```text
when ButtonStart.Click
  set SoundLevel1.AnalysisMode to "Spectrum"
  set SoundLevel1.ColorTheme to "Concert"
  set SoundLevel1.SilenceColor to make color (make a list 36 16 61)
  set SoundLevel1.Smoothing to 0.4
  call SoundLevel1.Start

when SoundLevel1.SpectrumChanged(low, mid, high, red, green, blue, color)
  set Screen1.BackgroundColor to get color

when ButtonStop.Click
  call SoundLevel1.Stop
```

위 내용은 블록 연결을 글로 표현한 예시입니다. `get color`는 이벤트 매개변수에서 꺼냅니다. `SilenceColor`에는 색상의 `make color`와 리스트의 `make a list`를 연결해 36, 16, 61을 넣습니다. 디자이너에서 무음 색상을 선택해도 됩니다.

Concert 테마는 저음에 선명한 보라 `#7C3AED`, 중음에 네온 핑크 `#FF3EB5`, 고음에 밝은 라벤더 `#C4A1FF`를 대응시키고 비율에 따라 혼합합니다. 추천 무음 색상은 어두운 보라 `#24103D`입니다.

`SpectrumChanged`의 `low`, `mid`, `high`는 각각 0~100의 비율이며, 소리가 있을 때 합계는 약 100입니다. `red`, `green`, `blue`는 각각 0~255이며 선택한 테마가 적용된 색상입니다. `color`는 화면 배경색에 바로 연결할 수 있습니다. 무음에서는 세 대역의 비율은 모두 0이고 화면에는 `SilenceColor`가 적용됩니다.

기존 `ColorChanged` 이벤트를 사용하고 있다면 그 이벤트의 `color`를 그대로 연결해도 됩니다. 배경색 설정은 한 이벤트에서만 처리하세요.

## 교실 환경에 맞추기

- 반응을 빠르게 보려면 `Smoothing`을 0.2~0.4로 낮춥니다. 깜빡임을 줄이려면 0.6~0.8로 높입니다.
- 음악을 꺼도 색상이 반응한다면 실내 잡음의 `Level`을 관찰하고 `NoiseGate`를 그보다 조금 높입니다. 기본값은 20입니다.
- 마이크가 스피커에 너무 가까우면 입력이 왜곡될 수 있습니다. 스피커와 거리를 두고 적당한 볼륨으로 시작합니다.
- 전체 화면을 덮는 배치 컴포넌트가 있다면 해당 배치의 배경색을 변경합니다.
- 앱이 배경으로 이동하면 측정이 중지됩니다. 돌아온 뒤 시작 버튼을 다시 누릅니다.
- 확장을 업데이트한 후에는 Companion을 완전히 종료하고 연결을 초기화한 뒤 다시 연결합니다.

## 수업에서 활용하기

저음·중음·고음의 비율을 레이블이나 막대로 표시하고 화면 색상과 비교해 볼 수 있습니다. 음악의 종류, 악기, 볼륨을 바꿔 보면서 “소리 크기”와 “주파수 구성”의 차이를 관찰하는 활동으로 확장할 수 있습니다.

테스트 음을 사용할 때는 125Hz, 1,000Hz, 4,000Hz를 차례로 재생해 대역별 반응을 관찰할 수 있습니다. 실제 스피커와 태블릿 마이크의 특성에 따라 결과가 달라질 수 있으며, 특히 작은 스피커는 저음을 충분히 재생하지 못할 수 있습니다.

## 검증과 제한

버전 4는 Java 컴파일, Android 실행 코드 생성, AIX 구조·마이크 권한·블록 정보 검사와 합성 신호를 이용한 대역 분석·테마 혼합·사용자 지정 무음색 검증을 통과했습니다. 실제 수업용 태블릿과 Companion에서의 환경별 호환성은 수업 전 확인이 필요합니다.

소리 크기 값은 상대값이며 소음계의 dB SPL이 아닙니다. Spectrum 모드는 기본 주파수나 음계를 판별하지 않으며, 음악의 주파수 분포가 비슷한 구간에서는 색상도 비슷하게 유지됩니다.
